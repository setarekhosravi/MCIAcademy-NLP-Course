# MCI Academy NLP Course

This repository contains my personal implementations and exercises for the Natural Language Processing (NLP) course offered by MCI Academy. The course covers fundamental concepts and advanced techniques in NLP and Large Language Models (LLMs).

## Course Progress

I'm currently in Week 3 of the course, focusing on word representations:
- Sparse representations (e.g., TF-IDF)
- Dense representations (e.g., Word2Vec, GloVe, etc.)

## Repository Structure

### Week 1: Probabilistic Language Models
- Implementation of basic probabilistic language models
- Unigram and bigram models
- Analysis of Persian poetry dataset
- Calculating word probabilities and sentence likelihood

### Week 2: Neural Feed-Forward Language Models
- Implementation of a simple feed-forward neural network for language modeling
- Processing and cleaning the Hamshahri corpus (Persian news dataset)
- Creating n-gram sequences for prediction
- Building and training a neural language model with TensorFlow/Keras

## Technologies Used
- Python
- TensorFlow/Keras
- NumPy
- Matplotlib
- Scikit-learn

## Learning Journey
This repository documents my learning journey in NLP, starting from basic probabilistic models and progressing toward more advanced neural network approaches. Each implementation includes detailed comments explaining the concepts and techniques being applied.
